# Constellation guide artwork

- `advance-lighting-heart.svg` adapts `mdi-heart` from [Pictogrammers Material Design Icons](https://github.com/Templarian/MaterialDesign), licensed under Apache License 2.0.
- `light-probe-starfish.svg` adapts [SVG Repo Starfish 100411](https://www.svgrepo.com/svg/100411/starfish), released under CC0.
- `realtime-global-illumination.svg` and `area-light-softbox.svg` are original GuGame artwork.

The source silhouettes were adapted into connected, wide-area guides so GuGame's SVG sampler, boundary baker, and connection pathfinding can use them as constellation maps.
